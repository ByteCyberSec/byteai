## CORE_THESIS
2026 is **the year of trust**. Every bet, prediction, and action top engineers take reduces to one question: *how much do you trust your agents?* Trust = speed = iteration = impact; the more you trust, the longer your agents run before a mistake you must correct. The model is no longer the limitation (Gemini 3 Flash: top-3 intelligence at top-5 price, ~200 tokens/s; Opus 4.5; competition = rising intelligence-per-token). The limitation is your ability to compose context, model, prompt, tools (the "core four") into trusted systems. Track record: 2023 24 bets/16 right, 2024 41/36, 2025 15/13 — ten bets for 2026 follow.

## KEY_TECHNIQUES — the 10 (+1) bets
1. **Anthropic becomes a monster** — bet on the best agent harness/tool-calling and consistent execution.
2. **Tool calling is the opportunity** — only ~15% of output tokens are tool calls (OpenRouter State of AI); tool calls ≈ impact; push longer chains of correct tool calls.
3. **Custom agents above all** — 50 lines of code + 3 tools + a 150-line system prompt can automate a massive problem; pick and lock in an agent SDK (e.g., Claude Agent SDK). Highest-ROI bet.
4. **Multi-agent orchestration** — one agent is not enough; run 3/5/10/hundreds; cross-validation ("what one planner misses, three will find").
5. **Agent sandboxes** — each agent gets its own computer; defer/lazy-load trust; best-of-N; only production matters.
6. **Inloop vs outloop** — inloop (terminal babysitting) vs outloop (Slack/Discord/GitHub prompts that deliver PRs); progressively offload to outloop, but own your agentic ring rather than letting a cloud tool own your source.
7. **Agentic Coding 2.0** — agents that conduct agents: a lead/command-level agent that plans, spawns, delegates, monitors, reviews, ships; you become the executive.
8. **Benchmark breakdown** — public benchmarks saturate (90–100% ceiling); build private evals for your own use cases.
9. **UIs vs agents** — agents eat SaaS; UIs become prompt interfaces; build minimal tool calling, not MCP bloat.
10. **AGI hype dies** — ignore AGI/ASI marketing; ship with agents.
11. *(Bonus)* First end-to-end agentic engineers emerge — the first blog post of a system that ships a feature prompt-to-production with zero human in the loop.
